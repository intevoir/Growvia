# Ikon Custom

Tempatkan file ikon custom di folder `assets/`:

| File | Kegunaan |
|------|----------|
| `assets/growvia-icon.png` | Ikon utama Growvia (di header README) |
| `assets/icon-farming.png` | Ikon sistem farming |
| `assets/icon-inventory.png` | Ikon inventori |
| `assets/icon-shop.png` | Ikon shop |
| `assets/icon-gacha.png` | Ikon gacha |
| `assets/icon-discord.png` | Ikon komunitas Discord |

**Penting:** Jangan gunakan URL `blob:https://...` — itu hanya berlaku di browser kamu saat ini dan tidak bisa diakses GitHub. Simpan gambar sebagai file asli (`.png`, `.jpg`, `.svg`), commit ke repo, baru bisa dipakai di README.
