# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅ Yes    |

## Reporting Vulnerabilities

If you find a security vulnerability, do not open a public issue. Send an email directly to the repository owner or use GitHub's "Report a vulnerability" feature.

Security reports will be answered within 7 business days.

## Scope

- Bot token and Supabase service role key in `.env` (never committed)
- Player data stored in Supabase
- Bot behavior on Discord

Thank you for helping keep Growvia secure.
